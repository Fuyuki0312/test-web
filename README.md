# test-web

A small playground for learning HTML and experimenting with a fantasy-themed website: the domain of the Soul Summmoner.

## Open locally

1. Download this repository as a ZIP and extract it, or clone it.
2. Open `index.html` in your browser.
3. Keep the `audio` and `images` folders beside the HTML files so the media paths work.

No package installation or build step is required.

## Files

| Path | Purpose |
| --- | --- |
| `index.html` | Main page with text formatting, lists, a table, audio, links, and sample form controls. |
| `ML_Soul_biography.html` | Secondary page linked from the main page. |
| `images/test.jpg` | Image displayed on the main page. |
| `audio/Invicible.mp3` | Background audio used by the main page. |
| `LICENSE` | Repository license. |

## Learning notes

- Styles are currently written directly in HTML attributes.
- The main page is configured to refresh every 30 seconds.
- Audio starts muted; use the audio controls to play or unmute it.
- The form is an HTML practice example; this repository does not include a backend for account creation. Use dummy input when experimenting.
